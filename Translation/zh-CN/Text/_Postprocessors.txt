# 【分类说明】
# 1. 核心专有名词
#    - 游戏核心术语：Vault, Dweller, Wasteland, Overseer, Pip-Boy, SPECIAL
#    - 组织机构：Vault-Tec, Minutemen, Brotherhood of Steel, Institute, Raiders
#    - 生物名称：Deathclaws, Radscorpions, Radroaches
# 2. 武器类型（1-2个单词）
#    - 手枪类：Pistol, Laser Pistol, Plasma Pistol
#    - 步枪类：Rifle, Laser Rifle, Assault Rifle
#    - 霰弹枪类：Shotgun, Combat Shotgun
#    - 其他：Minigun, Flamer, Missile Launcher
# 3. 装甲/服装类型
#    - 装甲类：Armor, Power Armor, Battle Armor
#    - 服装类：Outfit, Uniform, Jumpsuit, Suit
#    - 特殊服装：Vault Suit, Santa Suit
# 4. 房间/设施类型
#    - 居住设施：Living Quarters, Vault
#    - 生产设施：Diner, Medbay, Water Treatment, Power Generator
#    - 其他设施：Storage, Laboratory, Workshop, Garden
# 5. 游戏固定名称（任务/角色/地点）
#    - 任务名称：Bounty: XXX, The Mystery of Vault XXX
#    - 角色装备：Autumn's Laser Pistol, Amata's Jumpsuit
#    - 固定地点：Vault 199, Vault 789, Nuka-Cola plant
# 6. UI界面词汇
#    - 操作词汇：Menu, Save, Load, Settings, Cancel, OK
#    - 方向词汇：Up, Down, Left, Right
#    - 状态词汇：Ready, Level, Health, Stats
# 7. 时间单位
#    - 英文单位：second, minute, hour, day
#    - 缩写单位：s, m, h, d
# 8. 宠物类型
#    - 犬类：Dog, Hound, Shepherd, Retriever, Terrier
#    - 猫类：Cat, Persian, Siamese
# 9. 错译修正
#    - 保险库 → 避难所
#    - 金库 → 避难所
# 10. 特殊规则
#     - 正则表达式：\[-\]\s*\[-\]
#     - 格式修正：。。（句号重复）
