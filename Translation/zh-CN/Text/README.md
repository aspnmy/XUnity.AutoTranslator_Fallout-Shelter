### 🤖 NPC对话译文文件

`fallout_shelter_zh_NPCs.txt` 是专门的NPC对话译文文件，包含：

- **巧手先生对话** - 英式黑色幽默、机器人特色、服务精神
- **废土探索对话** - 生存压力、实用主义、环境观察
- **避难所居民对话** - 日常生活、工作态度、情感表达
- **敌对生物遭遇** - 战斗反应、危险预警、逃跑策略

**文件特点**:
- 采用标准"英文=中文"格式
- 从多个源文件提取汇总，确保无重复
- 便于NPC风格的统一管理和优化

**维护脚本**:
- `extract_npc_dialogues.py` - 从源文件提取NPC对话
- `cleanup_npc_sources.py` - 从源文件中删除已提取的NPC对话

- **废土探索对话** - 生存压力、实用主义、黑色幽默
- **避难所科技风格** - 企业文化、官方语气、规则明确
- **情感表达模式** - 正面/负面情感的不同表达方式
- **性格特征总结** - 各类NPC的核心性格要素

该文件为翻译工作提供了风格参考，确保译文符合《辐射》系列的游戏氛围和角色特色。
